# 구조

stdio가 기본 전송입니다. `createServer`가 상태, 검색, 분석, 정책, 보고서, 사건, 페이지 수집, 이미지 검색, 리소스, 프롬프트를 등록합니다.

검색은 데모 제공자와 카카오 다음 검색 중 하나입니다. 데모 모드는 합성 페이지만 반환합니다. URL은 정규화한 뒤 중복을 제거하고, 위험 점수와 일치 신뢰도는 `src/domain/scoring.ts`에서 따로 계산합니다.

지우개 경로의 기준은 `src/policy/eraserPolicy.ts` 한 곳에 있습니다. 확인일은 2026-10-25입니다.

감사 결과는 60분 메모리 캐시입니다. SQLite는 `DL_ENABLE_PERSISTENCE=true`이고 암호화 키가 유효할 때만 열며, 호출이 끝나면 닫습니다. URL, 제목, 스니펫은 AES-256-GCM으로 저장합니다.

공개 페이지와 이미지 주소는 사설망, 메타데이터 주소, 리다이렉트 목적지를 다시 검사합니다.
