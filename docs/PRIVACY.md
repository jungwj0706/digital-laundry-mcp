# 개인정보

외부 검색 동의 전에는 카카오 다음 검색으로 별칭을 보내지 않습니다. 이미지 동의 전에는 Vision으로 사진을 보내지 않습니다. 페이지 발췌도 접속 동의가 있어야 가져옵니다.

로그 필드는 이벤트, 도구 이름, 소요 시간, 결과 수, 오류 코드, 제공자, 상관관계 식별자입니다. 검색어, API 키, 이미지 바이트는 남기지 않습니다.

로컬 저장은 기본으로 꺼져 있습니다. 저장하더라도 별칭 원문, 검색어 원문, 이미지 바이트는 넣지 않습니다. 보존 기간이 지나면 사건 행을 삭제합니다. 원격 동기화는 없습니다.

내보내기 파일은 평문입니다. 삭제 확인 없이는 로컬 데이터를 지우지 않습니다.
